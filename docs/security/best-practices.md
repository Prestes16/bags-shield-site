# Security Best Practices

Follow these guidelines to keep your assets secure.

## Wallet Security

1. Use hardware wallets for large amounts
2. Never share your private keys
3. Enable 2FA when available
4. Verify transaction details before signing

## API Security

1. Store API keys securely (environment variables)
2. Rotate keys regularly
3. Use HTTPS only
4. Monitor API usage for anomalies

## General

1. Only use official Bags Shield app/API
2. Verify URLs before entering credentials
3. Keep software updated
4. Report suspicious activity immediately
