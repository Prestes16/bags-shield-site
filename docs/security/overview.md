# Security Overview

Bags Shield implements multiple layers of security to protect users and their assets.

## Architecture

- **No custody**: We never hold user funds or private keys
- **Server-side validation**: All transactions are validated server-side before execution
- **Rate limiting**: Protection against abuse and DDoS
- **Input sanitization**: All user inputs are validated and sanitized

## Best Practices

1. Always verify transaction details before signing
2. Use official Bags Shield app or API only
3. Never share your private keys or seed phrases
4. Enable 2FA when available

## Reporting Security Issues

If you discover a security vulnerability, please email security@bags-shield.com.
